# 🏪 Nisha Store - Management System

> Built by Nisha from Sadabad, UP - Entirely on Mobile Phone!

### 📱 Live Project Link
This project runs on Pydroid 3 (Android)

### ✨ Features
- 1. Add New Sale (Customer Name + Amount)
- 2. Show Total, Average & Top Customer Report
- 3. Auto Save Report to hisaab.txt with Date & Time
- 4. View All Customers with ID
- 5. Delete Customer by ID

### 🛠️ Tech Used
- Python 3
- SQLite3 (Database)
- File Handling (hisaab.txt)
- datetime module

### 🚀 How to Run
1. Open Pydroid 3
2. Copy Store.py code
3. Run & Choose Option 1-6
